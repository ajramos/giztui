# Support

GizTUI is an open-source project maintained by one person in spare time. Support
is provided best-effort through GitHub Issues.

## Where To Ask

- **Bugs and feature requests:** open a GitHub issue using the issue forms.
- **Security vulnerabilities:** use the private reporting route in
  `SECURITY.md`. Do not open a public issue.
- **General questions:** open an issue with the `question` label.
- **Documentation:** read `docs/` first; the documentation hub is
  `docs/README.md`.

There is no separate discussion forum or paid support channel. GitHub Issues
is the canonical backlog and the only supported way to reach the maintainer.

## What To Include

- GizTUI version (`giztui --version`) and platform.
- For desktop issues, whether it reproduces in the TUI.
- Reproduction steps and expected versus actual behavior.
- Relevant logs or configuration values, redacted of credentials and message
  content.

## Unsupported

- Commercial support or SLAs.
- Security backports to older releases beyond the latest published release.
- Guaranteed response times.
